# EECE 5644 - Pattern Recognition and Computer Vision

## Assignment 1

This repository contains the Python implementations, experimental results,
and visualizations developed for Assignment 1 of EECE 5644 - Pattern
Recognition and Computer Vision at Northeastern University.

## Requirements

- Python 3
- NumPy
- Pandas
- Matplotlib
- SciPy
- Scikit-learn

## Dataset

The datasets used in this assignment are not included in the repository due to their large file sizes.

### UCI Human Activity Recognition (HAR) Dataset

The Human Activity Recognition Using Smartphones dataset is publicly available through the UCI Machine Learning Repository.

Dataset Link:
https://archive.ics.uci.edu/dataset/240/humanactivityrecognitionusingsmartphones

Download and extract the dataset before executing the corresponding Python program.

### Other Datasets

Any additional datasets required for the assignment should be downloaded separately and placed in the appropriate directories.

## Running the Programs

Install the required Python libraries:

```bash
pip install numpy pandas matplotlib scipy scikit-learn
```

Execute the Python programs individually:

```bash
python Question1.py
python Question2.py
python Question3.py
```

Ensure that the required datasets are available in the file paths specified within the respective Python programs.

## Results

The repository includes generated plots, classification results, and experimental evaluations corresponding to the assignment questions.
